# openline-skills-lab

Experimental local skills. **Not OpenLine World.**

This repo holds three skill directories packaged exactly as they existed
in their source environment, with no modifications:

- `openline-protocol/` — OLP receipt persistence layer
- `openline-proof-adapter/` — proof receipt adapter
- `epistemic-swarm/` — swarm experiment scripts

These are a separate codebase from OpenLine World and should not be
blurred with it. Nothing here has been refactored; sources (including
existing bytecode caches) are preserved byte-for-byte as packaged.
